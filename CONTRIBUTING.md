# Contributing

Please read [development](docs/development.md), [architecture](docs/architecture.md) and [security](docs/security.md). Start with a reproducible issue or focused change. Include tests for new behavior and evidence requirements for diagnostic claims. Run formatting, unit tests, vet and Linux integration tests; run the race detector with a C compiler. Keep changes small and document platform or permission limitations. Never include real credentials or private system logs in fixtures.
